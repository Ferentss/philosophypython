
# Philosophy LMS

## Про проєкт

Philosophy LMS - сайт для вивчення філософії.
На ньому можна переглядати інформацію про
філософів, історичні епохи, філософські праці,
навчальні курси та уроки.

На сайті є реєстрація, вхід в акаунт і
особистий кабінет. Викладачі можуть створювати
курси та додавати до них уроки.

## Технології

- Python
- Django 5.2
- MySQL 8.0
- HTML, CSS, Bootstrap

## Структура проєкту

- `content` - курси, уроки, філософи, епохи та праці.
- `users` - користувачі та авторизація.
- `progress` - моделі для навчального прогресу.
- `templates` - HTML-сторінки.
- `static` - стилі та статичні файли.
- `philosophy_lms` - налаштування Django.

## Як запустити проєкт

Для запуску потрібні Python і MySQL 8.0.

### 1. Встановити залежності

Відкрити термінал у папці проєкту.

Створити віртуальне середовище:

```powershell
python -m venv .venv
```

Активувати його:

```powershell
.\.venv\Scripts\Activate.ps1
```

Встановити бібліотеки:

```powershell
python -m pip install -r requirements.txt
```

### 2. Налаштувати базу даних

Відкрити MySQL Workbench та створити базу:

```sql
CREATE DATABASE IF NOT EXISTS philosophy_lms_db
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
```

Для підключення потрібно мати користувача MySQL
з правами доступу до цієї бази.

### 3. Налаштувати .env

У кореневій папці створити файл `.env`
за прикладом `.env.example`.

У ньому потрібно вказати секретний ключ Django,
назву бази даних, користувача та пароль MySQL.

### 4. Застосувати міграції

```powershell
python manage.py migrate
```

### 5. Створити адміністратора

```powershell
python manage.py createsuperuser
```

### 6. Запустити сайт

```powershell
python manage.py runserver
```

Після запуску сайт буде доступний за адресою:

http://127.0.0.1:8000/

Адмін-панель:

http://127.0.0.1:8000/admin/

## Ролі користувачів

На сайті є студенти та викладачі.

Студенти можуть переглядати доступні курси
та навчальні матеріали.

Викладачі можуть створювати курси й уроки,
а також редагувати власні записи.

Адміністратор керує користувачами та даними
через Django Admin.

## База даних

У проєкті використовується MySQL 8.0.
Таблиці створюються за допомогою міграцій Django.

Основні моделі: Era, Philosopher, Text,
Course, Lesson та CustomUser.
Вони пов'язані між собою через ForeignKey.

Налаштування підключення до бази даних
зберігаються у файлі `.env`.
